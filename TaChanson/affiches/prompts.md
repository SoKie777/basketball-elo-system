# Prompts d'images · Ta Chanson

Les 3 affiches PNG de ce dossier sont **déjà prêtes à publier**. Ces prompts servent seulement si tu veux d'autres versions avec un générateur d'images (ChatGPT, Ideogram, Canva…).
Les générateurs écrivent mieux le texte quand il est court et entre guillemets. Vérifie toujours l'orthographe sur l'image : si une lettre est fausse, régénère ou corrige dans Canva.

Règles communes : palette **orange (#F77F00) et vert (#009E60)** sur fond crème ou orange, style illustration moderne et festif, **aucune personne réelle, aucun artiste, aucun logo de marque**, mention IA visible.
